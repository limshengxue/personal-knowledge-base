# Agentic AI

## Overview

Agentic AI combines language models with tools, context, planning, execution, and feedback loops so a system can work toward a goal rather than only produce a single response. This topic map focuses on agent capabilities, orchestration, coding-agent workflows, and the supporting context and control mechanisms.
