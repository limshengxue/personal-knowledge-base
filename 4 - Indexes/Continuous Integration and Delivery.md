# Continuous Integration and Delivery

## Overview
Continuous integration automates checks on code changes, such as builds, tests, and linting. Delivery workflows prepare or deploy validated changes using controlled environments and credentials. This index groups automation platforms and execution resources, with attention to repeatability, deployment gates, and the authority granted to jobs.
