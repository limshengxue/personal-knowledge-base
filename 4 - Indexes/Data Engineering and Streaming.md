# Data Engineering and Streaming

## Overview
Data engineering organizes how data moves between systems and becomes useful through processing. Batch workflows coordinate scheduled tasks, while streaming systems process ongoing events. This index brings together workflow orchestration, event transport, stream processing, and the contracts and timing expectations that connect them.
