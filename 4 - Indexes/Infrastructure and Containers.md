# Infrastructure and Containers

## Overview
Infrastructure supplies the operating environments and connectivity that applications need. Containers package workloads, while orchestration coordinates their placement, lifecycle, and access to resources. This index links host-level tools with container platforms, networking, and sensitive configuration; it focuses on running workloads rather than designing application code.
