# 6 Selecting Coding Agent
Why choose coding agent over IDE
- CLI agent can be deployed to any environment including server, docker
- It shares same environment/action spaces as the development which is the Terminal
![[Attachments/Pasted image 20260411133623.png]]

## The difference between 3 main stream coding agent
### Design Philosphy
- Claude Code -  Workflow Engine
	- Hooks, full repo navigation, Git integration
	- Agentic Autonomy with very strong extensibility 
- Gemini CLI - Conversational Context Engine
	- Huge context window, google search integration
- Codex CLI - Precision Editing Assistant
	- Clear and safe design with patch-based and diff-based document edits
	- Sandboxing
