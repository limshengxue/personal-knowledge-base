# 13 - KISS and YAGNI Principle
## KISS
- Keep it simple and stupid
- Try to not over-use technique that other may not understand, e.g *regex*, certain niche syntax
- Do not reinvent the wheels but leverage existing libraries
- Do not overoptimize
- Hard to make judgement. Code review can helps.

## YAGNI
- You ain't gonna need it.
- For example, writing implementation that we currently do not required (might as well just have abstract class that allow later extension)
- Importing dependencies that we don't need
