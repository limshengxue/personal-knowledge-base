# 7 - Object-Oriented Analysis and Design
- The process of analysing requirement and designing before implementing OOP

## Class Identification
- Define the functional requirements
- Define class according to the function requirements
	- Inspect which functions operates on similar attributes and work closely

## Class Definition
- Define the method and attributes of classes according to the verb and noun in functional requirements

## Relationship Definition
- Generalization =  Inheritance,`extends`
- Realization = `implements`
- Composition, in textbook this can split into 3 which practically can be though as 1
	- Aggregation (If A aggregate B, B is an attribute of A but can exist individually)
	- Composition (If A aggregate B, B is an attribute of A but cannot exist individually)
	- Association - can be either aggregation or composition
- Dependency - week association, include associated but also include when a method refer to another class 

## Join the class and provide execution Entity
- Join the classes and an provide an entry either through `main()` or API endpoint
