# 1 - How to judge quality of code
- There are multiple coding standards and judging them can be subjective
- Here are some common one

## Maintainability
- Can add or change code without huge difficulty or risk to introduce new bugs
- Affected by layered, modularisation, cohesive, coupling


## Readability
- Affected by naming, comment, function size, modularisation

## Extensibility
- Able to add function without or with minimal changes to existing code

## Flexibility
- Affected by extensibility, reusability, and good interface design

## Simplicity
- Keep it Simple, Stupid (KISS)

## Reusability
- OOP inheritance, polymorphism
- DRY (don't repeat yourself)

## Testability
- Unit test can be easily developed
