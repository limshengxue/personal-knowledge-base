# Coding Assistant
- We build coding assistant by giving LLM a set of tools
- It iterate the process of Gather Context -> Plan -> Take Action

## Tools
- Models are given plain text direction on how to response in a way that could invoke tool
- The coding assistant invoke the tool when receive the response
- Strong tool use allow
	- Tackling harder tasks
	- Extensible
	- Improved security
