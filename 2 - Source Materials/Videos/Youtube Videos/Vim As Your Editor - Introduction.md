# Vim As Your Editor - Introduction
## Modes
- Normal Mode - can move cursor (default)
- Insert Mode - can type like regular editor (press i to go into insert mode, press `Esc` to exit)
- Visual Mode - highlight while moving (press v to go into visual mode)
- Command Mode - with a `:`

## Normal Mode
### Navigating Around
- `jk` - move down and up
- `hl` - move left and right
- `w` - move forward by words
- `b` - move backward by words
- Command Count Motion:
	- `3j` - move down by 3 times

### Editing
- `dd` - delete the current line
- `u` - undo
- `ctrl + r` - redo

## Visual Mode
- `y` - copy
- `p` - paste
