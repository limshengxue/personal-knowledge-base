# LLM Knowledge Bases

**Author:** Andrej Karpathy  
**Source:** X  
**Original post:** https://x.com/karpathy/status/2039805659525644595

## Summary

Karpathy describes using LLMs to build persistent personal knowledge bases for research topics. Instead of repeatedly asking an LLM to re-read raw sources, the workflow turns articles, papers, repositories, datasets, images, and other material into a curated knowledge layer stored primarily as Markdown and images.

The key idea is to shift LLM usage from one-off conversations toward continuously maintaining and improving structured knowledge that can be revisited, searched, linked, and expanded over time.

## Key ideas

- Use LLMs not only to manipulate code, but also to manipulate and organize knowledge.
- Keep source material and convert it into a structured Markdown-based knowledge base.
- Let the LLM synthesize, reorganize, cross-reference, and update knowledge over time.
- Use tools such as Obsidian to browse and work with the resulting wiki.
- Treat knowledge-building as a compounding process rather than disposable chat sessions.
