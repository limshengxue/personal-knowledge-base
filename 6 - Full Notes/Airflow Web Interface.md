# Airflow Web Interface
## To run the web server
`airflow webserver -p 9090`


## Useful Features
- DAG Tab
	- Owner
	- Run 
	- Schedule
- DAG details
	- Graph
	- Tree
	- Code (read-only) - useful for troubleshooting
- Audit Logs
	- Show the events occurred
- DAG runs
	- Show the executions of the DAG
