# Active Learning and the Feynman Technique
- Active learning turns input into something you can explain, use, or test.
- The source recommends discussion, practice, and teaching instead of treating reading alone as mastery.
- The Feynman technique is used here as a practical explanation-and-revision routine, not a claim about guaranteed retention rates.

## Explanation Loop
1. Choose one concept and state what you should be able to do with it.
2. Explain it in plain language without copying the source.
3. Mark places where the explanation becomes vague or depends on unexplained jargon.
4. Return to the material to resolve those gaps.
5. Revise the explanation and apply it to a concrete example.

## Connect Knowledge to Use
- Relate a new idea to a problem you have already encountered.
- Compare it with an adjacent concept rather than collecting isolated definitions.
- Build a small example, answer a question, or teach someone the distinction.
- Use feedback to find misunderstandings that confident reading can hide.

For SQL window functions, explain why rows remain separate, then write a query and inspect its output. The result tests understanding more directly than a reading streak.

## Input Still Matters
- Reading and lectures provide vocabulary, examples, and background; they are not inherently useless.
- Early experimentation can make a topic concrete, but deeper work requires returning to its principles.
- Select relevant material deliberately rather than using unfinished books as evidence of failure.

## Useful Progress Evidence
Keep an explanation, worked example, or corrected mistake. When progress feels uneven, use [[Patience and Learning Plateaus]] to review the practice method instead of merely extending the reading schedule.
