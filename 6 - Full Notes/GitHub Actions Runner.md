# GitHub Actions Runner
## GitHub Hosted
- Automatic updates
- Managed and maintained by GitHub
- Clean instance for every job execution

## Self-Hosted
- Open source
- Automatic updates for self-hosted runner application only
- Customizable
- Responsible for the cost of runner machines

## Runner Groups
- Configure on enterprise or organization level
- Scope runners to specific organizations and/or repo
- Move runners between groups
