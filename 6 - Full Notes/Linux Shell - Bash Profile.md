# Linux Shell - Bash Profile
## Setting up Alias
- Can setup in `.bashrc` 
	- Example like `alias d='ls -lt |grep "^d"'
	- Need to source the file using `. ~/.bashrc` to see the changes
	- Source means to execute the file
